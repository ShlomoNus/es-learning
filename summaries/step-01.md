# Step 1 — What Elasticsearch Is

## Main points
- Elasticsearch stores JSON documents and is optimized for search and analytics.
- Useful starting analogy: SQL table ≈ Elasticsearch index, row ≈ document, column ≈ field.
- The analogy is only conceptual; Elasticsearch is not a relational database.
